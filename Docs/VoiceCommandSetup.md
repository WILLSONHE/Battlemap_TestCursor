# 战斗语音命令（Voice Command）

## 前置条件

- **平台**：Windows 64 位（使用系统 SAPI 听写）。
- **语言包**：Windows 设置 → 时间和语言 → 语言和区域 → 添加 **中文（简体）** → 勾选 **语音识别** 并下载语言包。
- **麦克风**：主菜单 → **设置** → 选择 **语音命令麦克风**，按住 **测试麦克风** 查看输入音量条。

所选设备会保存到 `GameUserSettings.ini`（`[BattleVoice]`），战斗内按住 M 时 SAPI 会按 **设备显示名称** 匹配系统语音输入（WASAPI 设备 ID 与 SAPI 令牌 ID 不同，不能只比 ID）。

**按住 M 时请一直按住到说完再松开**；松开后会再拉取一轮识别结果。若仍无文字，请确认已安装 **中文（简体）语音识别** 且 Windows 默认识别语言为中文。

若识别器初始化失败，屏幕中央会提示安装中文语音包；可用 **F9** 验证解析与执行链路（无需麦克风）。

## 操作

| 按键 | 作用 |
|------|------|
| **按住 M** | 按住说话，**松开 M** 后执行（可说「命令：…」也可不说） |
| **F9** | 调试：注入 `命令1营移动到0,0`（不要用 `~`，会打开 UE 控制台） |

## 指令格式（口语）

识别并规范化后显示为 `命令：……`，坐标为 **地形格 (x,y)**（与 HUD 地形格一致）。

1. **移动**：`命令 1营 移动到 10，20` → `命令：1营移动到10，20`
2. **停止**：`命令 1营 停止移动`
3. **攻击**：`命令 1营 攻击位于 5，6 的敌方单位`

单位名与编组 **战斗序列** 标签一致（如 `1营`、`1营1连3班`）。

## 测试清单（PIE / Standalone）

- [ ] 已装中文语音识别 → 按住 M 说「命令」+「1营移动到 0，0」→ 友军向格 (0,0) 移动，中央显示命令文本
- [ ] `命令 1营 停止移动` → 单位停止
- [ ] 格点附近有敌军 → `命令 … 攻击位于 x，y 的敌方单位` → 下达攻击
- [ ] 通讯 Jammed 的单位被跳过（与右键命令一致）
- [ ] 无语言包时提示错误且不崩溃
- [ ] 按 **F9** 可触发调试移动（无需麦克风）
